# Example request files

These are templates for repositories with the named paths/toolchain, not universal commands. Inspect/adjust them before submitting. They do not contain evidence or valid proof of any completed review.

`checks-node.json` registers an existing meaningful npm test script; it does not run it. `task-batch.json` demonstrates two parallel audits followed by a dependent review. Submit an applicable request through `node /path/to/plugin/bin/far.mjs request --file request.json --root /path/to/repo` after initialization.

Model-facing native task dispatch and interactive examples are in [the examples guide](../docs/EXAMPLES.md).
